# Weather Check Website

This project uses **HTML**, **JavaScript**, and **C++**  to display weather information fetched from the **OpenWeatherAPI**. It allows users to search for cities, view the current weather, and toggle between Celsius and Fahrenheit units.

**Try here:**  
[Live demo](https://caydeny.github.io/Weather-Check/)

## Features
- **Search for any city** to view the current weather, including temperature, wind speed, humidity, and more.
- **Toggle between Celsius and Fahrenheit** to view temperatures in your preferred unit.
- **Location-based weather:** If you allow geolocation, it fetches weather data based on your current location.
